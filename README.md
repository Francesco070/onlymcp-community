# OnlyMCP

Your skills, agent definitions and markdown memory in the cloud, the same in every MCP client on every device.

This repository is OnlyMCP's public place for bug reports, feature requests and release notes. OnlyMCP is a hosted
service: its source code is private and is not in this repository.

## Connect

Add the remote MCP server `https://only-mcp.com/api/mcp` to your client (Streamable HTTP, OAuth 2.1). Setup for
Claude, ChatGPT, Cursor and other clients: https://only-mcp.com/docs

- **Memory:** read, write, search and link markdown notes from any client
- **Skills and agents:** kept once, loaded when a conversation needs them
- **Gateway:** connect your other remote MCP servers once and reach their tools through the same connection

Listed in the official MCP Registry as `com.only-mcp/onlymcp`. CLI: `npx onlymcp`. Free plan at
https://only-mcp.com

## Report a bug or ask for a feature

[Open an issue](https://github.com/Francesco070/onlymcp-community/issues/new/choose). Issues are public, so leave
out tokens, passwords and the content of your memory files.

## Security

Please do not report a vulnerability in a public issue. [SECURITY.md](SECURITY.md) says how to report it privately.
